# Безопасность
- Токен бота — только в `.env` (в `.gitignore`), исходный `api/tg_bot.rtf` не коммитить; перед публикацией репо **перевыпустить токен** в @BotFather, если файл когда-либо попадал в git/облако.
- Бот не запрашивает и не хранит OpenRouter-ключи пользователей. Просим только вставлять их локально: `loosechange add … --key-file <файл>` читает ключ из локального файла и пишет в `~/.hermes/.env` (бэкап, права 600, в выводе только маска `sk-or-v1-…abcd`); через бота ключ не проходит. Для DeepSeek Harness ключ пишется в `~/.dsh/.env` по тем же правилам. VibeForge хранит ключ открытым текстом в своей БД (`app_settings.OPENROUTER_API_KEY`); `--key-file` пишет туда же, только при закрытом приложении и после бэкапа БД (бэкап тоже содержит ключ, права `600`).
- Логи без текста сообщений; хранится лишь user_id для антифлуда (in-memory).
- CLI пишет только в известные конфиги, всегда с бэкапом и `--dry-run`; без `sudo`.
- Данные OR — недоверенный ввод: id/имена экранировать (MarkdownV2/HTML), не подставлять в shell без quoting.
- Action использует только `GITHUB_TOKEN`; секретов бота в CI нет.
- Кнопка «Скопировать команду» в боте отдаёт `uvx loosechange …` (или `LOOSECHANGE_CLI`). Имя `loosechange` на PyPI на 2026-10-13 **свободно** — до публикации пакета его может занять кто угодно, и скопированная команда запустит чужой код. Перед публичным запуском бота: опубликовать пакет на PyPI или задать `LOOSECHANGE_CLI="uvx --from git+https://github.com/<you>/loosechange loosechange"`.
