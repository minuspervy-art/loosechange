# Сценарий бота

Язык интерфейса: RU по умолчанию, EN через `/lang` (строки в `i18n/`).

## Команды
`/start` — приветствие; `/top` — общий топ без вопросов; `/pick` — подбор под задачу; `/model <id>` — карточка; `/add` — как добавить последнюю выбранную модель; `/new` — что нового/исчезло за 7 дней; `/about`.

## /pick — максимум 3 вопроса, все кнопками
1. **Для чего модель?** Код · Агент с инструментами (Hermes/VibeForge) · Чат/общие вопросы · Рассуждения/математика · Длинные документы · Быстро и дёшево (классификация/саммари) · Дизайн/вёрстка · «Не знаю» (→ задаём уточнение свободным текстом, маппим на профиль простыми правилами; LLM-классификатор — только v2).
2. **Куда будет подключена?** Hermes · VibeForge · DeepSeek Harness · Другое (определяет формат сниппета; кнопки 2×2).
3. **Что важнее?** Максимум качества · Стабильность (uptime) · Большой контекст. Влияет на веса/штрафы.
Вопрос пропускается, если ответ очевиден (например, из `/pick agent`).

## Ответ
Топ-5 карточками + кнопки «🔧 Добавить в Hermes / VibeForge» → бот присылает: сниппет в моноширинном блоке, однострочник CLI, 2 строки о нюансах (rate limit, нужен ли ключ).

## Ограничения
Антифлуд 1 запрос/2 с на юзера; сообщение > 4096 симв. режется пагинацией; данные старше 12 ч → в футере «данные от <время>».

## Реализация (этап 3)
Код: `src/loosechange/bot/` — `handlers.py` (команды, коллбэки, антифлуд), `dialog.py` (кнопки, callback-data, правила свободного текста), `render.py` (HTML-карточки, пагинация, сплит > 4096), `i18n.py` (строки RU/EN — модуль вместо каталога `i18n/`: строк мало, один файл проще), `store.py` (снапшот с диска по mtime или по URL), `main.py` (long-polling).
- `/top [профиль]` — профиль `chat` (общий интеллект) по умолчанию; `/top coding` и т. п. тоже работают.
- `/pick [профиль] [hermes|vibeforge|other]` — пропускает вопросы 1–2, если ответ дан аргументом.
- «Не знаю» → свободный текст → правила-ключевые слова (`dialog.RULES`, порядок важен; fallback `chat`).
- «Быстро и дёшево» сейчас недоступен (нет данных скорости, см. RANKING.md) → бот сообщает об этом и показывает `chat`.
- `/model <id>` принимает id без `:free`; `/model <N>` — N-я модель последнего списка пользователя.
- Кнопки «🔧 Добавить» ссылаются на **саму модель**: callback-data = профиль, цель и короткий ключ модели (`sha1(id)[:10]`, ≤ 64 байт). Обновление данных по таймерам (каждые 15 мин) кнопки не ломает. Первая версия ссылалась на «место N в снапшоте версии X» и после каждого обновления отвечала «Устарело» — с таймерами это случалось постоянно, поэтому схему заменили (2026-10-13).
- Если модель за это время перестала быть бесплатной — сообщение «Этой модели больше нет среди бесплатных» с кнопками ниже.
- **Нижняя строка под каждой подборкой: «🏠 Меню | 🔄 Обновить»**. «Обновить» пересобирает ту же подборку (профиль, приоритет, харнес) на текущих данных — правкой того же сообщения; если ничего не изменилось, сообщение не дублируется. «Меню» — приветствие с кнопками «🎯 Подобрать · 🏆 Топ · 🆕 Что нового» (то же под `/start`). Под сниппетом и карточкой — «🏠 Меню».
- Если состояние диалога потеряно (бот перезапускался между вопросами), нажатие на вопрос 3 начинает `/pick` заново, а не падает.
- **Добавление в одну кнопку** (после выбора модели и харнеса): под сниппетом кнопка Telegram `copy_text`. Для Hermes — «📋 Скопировать команду» (`… add <id> --to hermes --profile <p> --apply`: бэкап + запись + smoke-проверка, затем подсказка, если для Hermes не задан `OPENROUTER_API_KEY`); для VibeForge/«Другое» — «📋 Скопировать id модели» (автозаписи нет). Бот сам не может писать на диск пользователя, а скачиваемые `.sh`/`.command` не используем: macOS их блокирует, и приучать запускать скрипты из бота небезопасно. Лимит `copy_text` — 256 символов, длиннее — кнопка не показывается.
- Карточки показывают обратный отсчёт до отключения бесплатного доступа (`expiration_date`): «⏳ бесплатно до 2026-10-31 (через 18 дн.)», за 7 дней — «скоро исчезнет»; `/new` сортирует такие модели по сроку. `/about` — когда обновлён список и таймеры обновления.
- DeepSeek Harness (с 2026-10-14): сниппет — YAML-оверлей профиля, кнопка «📋 Скопировать команду» (`… --to deepseek --apply`). Если харнесс не выбран в вопросе 2, у каждой модели три кнопки: Hermes · VibeForge · DeepSeek.
- Для VibeForge терминальной команды нет (применять локально нечего): сниппет = поля для UI + кнопка «📋 Скопировать id модели».
- Ответ на последний вопрос `/pick` приходит **правкой того же сообщения** (вопрос превращается в топ) — 2 вызова Telegram API вместо 3; на нажатие кнопки бот отвечает до любой работы, чтобы Telegram не счёл query устаревшим.
- Команда под кнопкой «📋 Скопировать команду» = **явный выбор модели**: Hermes — `--force` (заменить алиас `free-<профиль>`), DeepSeek Harness — `--force` (заменить модель по умолчанию), VibeForge — `--make-default`. Бэкапы как обычно. CLI находит снапшот проекта из любой папки (`./data`, `$LOOSECHANGE_DATA`, папка проекта, `~/Library/Application Support/loosechange/data`) — иначе при запуске из `~` терялись вердикты 🔒 (найдено 2026-10-14).
- **«⚡ Установить в один клик»** (2026-10-14) — URL-кнопка под сниппетом Hermes / VibeForge / DeepSeek Harness, если задан `LOOSECHANGE_LINK_BASE` (https-адрес опубликованной папки `site/`). Telegram пускает в кнопки только `http(s)`/`tg://`, поэтому кнопка ведёт на `site/add.html`, а страница передаёт `loosechange://add?model=…&to=…&profile=…` обработчику на компьютере пользователя (ставится `scripts/macos/install.sh`). Работает при любом размещении бота (VPS тоже): установка идёт у пользователя, бот только строит ссылку. Для 🔒-моделей в VibeForge кнопки нет. С телефона установить на компьютер нельзя — страница об этом говорит.
- Пагинация по 5 карточек; кнопка «Показать все (N)» ведёт на стр. 2, дальше ◀ ▶.
- Антифлуд — outer-middleware, 1 апдейт / 2 с на user_id; лишние апдейты молча отбрасываются (для кнопки — тост «Не так быстро»).
- Самопроверка: `uv run python scripts/bot_selfcheck.py` → [reports/bot-selfcheck.md](reports/bot-selfcheck.md) (реальные handlers, Telegram API подменён). Скриншотов из живого Telegram нет: писать боту от лица владельца агент не может — нужен ручной прогон.
