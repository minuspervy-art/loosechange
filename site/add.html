Установить на этом компьютере

Откроется приложение loosechange: оно покажет, что изменится, и ничего не запишет без вашего подтверждения. Перед записью делается бэкап.

Похоже, вы на телефоне. Установка работает на компьютере, где стоит loosechange, — откройте эту ссылку там (например, в Telegram Desktop).

Ничего не происходит?

Нужен обработчик ссылок loosechange (macOS). Установка, один раз:

git clone https://github.com/minuspervy-art/loosechange
cd loosechange && bash scripts/macos/install.sh
