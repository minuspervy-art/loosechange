Работаешь автономно, без уточняющих вопросов, до полностью рабочего результата. Проект: ~/Documents/PROJECTS/loosechange — open-source Telegram-бот + CLI, который ранжирует бесплатные модели OpenRouter по бенчмаркам, подбирает под задачу пользователя и добавляет выбранную модель в Hermes или VibeForge.

1. Прочитай README.md, CLAUDE.md и все файлы docs/ — архитектура, ранжирование, диалог, интеграции, безопасность и roadmap уже решены; следуй им. Отклоняйся только если факты (API, конфиги) этого требуют, и фиксируй причину в docs/.
2. Токен бота лежит в .env (TELEGRAM_BOT_TOKEN). Никогда не выводи его в чат/логи, не коммить .env и api/. Ключа OpenRouter может не быть — /api/v1/models публичный.
3. Иди по docs/ROADMAP.md этапами 0→6. На каждом этапе: код + тесты (pytest, ruff) + обновление доков, затем git commit (git init в начале; язык коммитов EN). Не переходи дальше при красных тестах.
4. Collector использует встроенные в OpenRouter `benchmarks.artificial_analysis`/`design_arena`; модели без бенчмарков = `unrated`, оценки не выдумывать.
5. Этап 3: запусти бота реально (long-polling), проверь /start, /top, /pick в живом Telegram (через бот-токен; если нужно взаимодействие от лица пользователя — сделай самопроверку через тестовые вызовы handlers и сообщи, что требуется ручной прогон).
6. Этап 4–5: Hermes — изучи `hermes --help` и ~/.hermes/config.yaml, реализуй адаптер с dry-run, бэкапом и ruamel.yaml; тестируй ТОЛЬКО на копии конфига. VibeForge — исследуй ~/Library/Application Support/com.vibeforge.app/data и ресурсы приложения (read-only; не трогай license-key, backend-token), опиши формат в docs/INTEGRATIONS.md; если безопасная автозапись невозможна — сделай docs/vibeforge-manual.md.
7. Этап 6: GitHub Actions (cron collect + ci), Dockerfile, quickstart в README. Репозиторий на GitHub не создавай и ничего не публикуй без моего подтверждения.
8. Финиш: прогон всех тестов, итоговый отчёт — что готово, что проверено вживую, что требует моих действий (перевыпуск токена перед публикацией, ключ OpenRouter, публикация репо).
