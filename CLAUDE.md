# CLAUDE.md — loosechange
Open-source (MIT) бот+CLI подбора бесплатных LLM с OpenRouter. Читай README.md и docs/ перед работой; ключевые решения уже приняты в docs/ARCHITECTURE.md — не пересматривать без причины.
- Не путать с Claude-скиллом `loosechange` (счётчик расходов) — это другой проект.
- Секреты: `.env` (токен бота лежит там). Никогда не печатать токен, не коммитить `.env` и `api/`.
- Данные не выдумывать: нет бенчмарка → `unrated`.
- Любая запись в чужие конфиги (Hermes/VibeForge) — dry-run + бэкап; тесты только на копиях.
- Документацию обновлять вместе с кодом; результаты исследований (VibeForge) писать в docs/INTEGRATIONS.md.
- Язык: код/коммиты на EN, пользовательские тексты бота RU+EN, доки RU.
